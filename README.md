# George Kalua – website

Static website, ready for Vercel. No build step needed.

## Before you deploy
1. If your Vercel address will be different from https://george-kalua.vercel.app,
   find and replace that address in: index.html, robots.txt and sitemap.xml.
2. Optional: paste your Microsoft Bookings or Calendly link into BOOKING_URL
   near the bottom of index.html.

## Update the site later
Edit the files on GitHub. Vercel redeploys automatically after every change.
